# Data Directory

## UNSW-NB15 Dataset

- **Source:** Kaggle - UNSW-NB15 Network Intrusion Detection
- **Total Samples:** 257,673
- **Training Set:** 206,138 samples (80%)
- **Testing Set:** 51,535 samples (20%)
- **Features:** 45 network traffic features
- **Target Classes:** 10 attack categories + benign

### Download Instructions

```bash
kaggle datasets download -d mrgloom/unsw-nb15
unzip unsw-nb15.zip
```

- UNSW_NB15_training-set.csv
- UNSW_NB15_testing-set.csv
