# UNSW-NB15 Network Intrusion Detection - ML Capstone Project

## Project Overview

This project applies Machine Learning to detect network intrusions using the UNSW-NB15 dataset.

## Dataset

- **Total Samples:** 257,673
- **Training Set:** 206,138 samples (80%)
- **Testing Set:** 51,535 samples (20%)
- **Features:** 45 network traffic features

## Technologies Used

- Python 3.13
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook
